FFmpeg (video playback) - LGPL-2.1-or-later
-------------------------------------------
Both builds link FFmpeg 6.1.2 DYNAMICALLY; no GPL or non-free FFmpeg
components are enabled or shipped. Text: licenses/LGPL-2.1.txt

Because linking is dynamic, you may replace these libraries with your own
compatible FFmpeg build (LGPL section 6): on the cart, swap the libav*/libsw*
.so files inside the .uce's lib32/; on Windows, swap the av*/sw* DLLs next to
the exe.

* Device cart: shared armhf libraries built from the UNMODIFIED source at
  https://ffmpeg.org/releases/ffmpeg-6.1.2.tar.xz
  using the Bootlin armv7-eabihf glibc-2.31 stable 2020.08-1 toolchain
  (https://toolchains.bootlin.com) and this exact configuration:

    ./configure --enable-cross-compile --cross-prefix=<toolchain>/bin/arm-linux- \
      --arch=armv7 --cpu=cortex-a53 --target-os=linux --prefix=<out> \
      --enable-shared --disable-static --disable-programs --disable-doc \
      --disable-network --disable-autodetect --disable-everything \
      --enable-decoder=h264,hevc,mpeg4,mpeg2video,mjpeg,png,vp8,vp9,aac,mp3,ac3,pcm_s16le \
      --enable-demuxer=mov,avi,matroska \
      --enable-parser=h264,hevc,aac,mpeg4video,mpegvideo,mpegaudio,mjpeg,png,ac3,vp8,vp9 \
      --enable-protocol=file --enable-swscale --enable-swresample --enable-neon \
      --extra-cflags="-O2 -D_FILE_OFFSET_BITS=64"

* Windows: unmodified DLLs from BtbN's FFmpeg-Builds "win64-lgpl-shared"
  package; corresponding sources are published with each release at
  https://github.com/BtbN/FFmpeg-Builds/releases

Device cart runtime libraries
-----------------------------
The cart (.uce) bundles a subset of the runtime libraries from the
OnesaUCE / AtGames Legends Ultimate device image, so the app can run from a
noexec USB drive on hardware the user already owns. These are unmodified
copies of files present on every target device, including: SDL2 (zlib),
libcurl (curl license), OpenSSL, ALSA (LGPL-2.1, source:
https://www.alsa-project.org), glibc runtime components (LGPL-2.1, source:
https://ftp.gnu.org/gnu/libc/), and the Rockchip/ARM Mali GPU userspace for
the rk3328 board (proprietary). Also reused, with the OnesaUCE project's
permission: its script-runner core (core.so) and sudo helper binary (sudo is
distributed under an ISC-style license, https://www.sudo.ws/about/license/).
